Task Inventory — Detailed Breakdown

Initial System Modeling & Eigenvalue Analysis

Task 1: Generator: 69MW, 11kV; Excitation IEEET1S; Governor IEEE3; lines 80km. Run eigenvalue analysis → extract critical eigenvalues (real part, osc frequency, damping ratio %), participation factor, identify electro-mechanical modes.

Small Signal Stability & Fault Response

Task 2: 3‑phase fault at Bus 2 (5s, clear 5.1s). Plot active power through transmission line. Save CSV for time-domain comparison. Record oscillations.

Task 3: Line length 200km, x=0.4Ω/km. Recompute eigenvalues: critical real part, damping ratio. Participation factor identification. Compare dynamic response with base case.

Task 4: 3‑phase fault (long line). Apply fault at Bus 2, clear 5.1s → plot active power, compare CSV with Task 2. Observe reduced damping.

Power System Stabilizer (PSS) Tuning

Task 5: Add PSS_STAB1 model to generator. Extract critical eigenvalue (real part, frequency, damping ratio). Note improvement in damping ratio. Find participation factor.

Task 6: PSS + Fault Response. Apply 3-phase symmetrical fault at Bus 2 (5s–5.1s). Plot active power, compare CSV with Task 4. Observe oscillation damping enhancement.

Task 7: Parameter Sweep on PSS. Test different PSS gains & time constants → evaluate damping factor improvement and system responses.

📁 DIgSILENT PowerFactory · CSV export · Modal analysis

Frequency Stability & Generator Outage

Task 4 (Frequency): Add 20MW generator (11kV) via 50MVA transformer. Run time domain 20s. Outage of G2 → plot frequency response. Extract NADIR, over-frequency, RoCoF.

Task 5: Load increase 10% at 5s. Increase active & reactive load by 10% at t=5s. Record frequency indices: nadir, RoCoF, steady-state error.

Task 6: External Grid loss. Remove external grid connection at 5s → islanded frequency behavior. List NADIR, over-frequency, RoCoF.

📁 DIgSILENT PowerFactory · CSV export · Modal analysis

Long-Term Voltage Stability (QV/PV)

Task 1 (Voltage): P-V curve & VSM. Increase load to 80MW, 0.8pf, Transformer2 to 100MVA. Plot P-V curve → compute Voltage Stability Margin (VSM) and bus sensitivity dV/dP.

Task 2: QV curve & compensator. Plot QV curve load bus → calculate Reactive Power Margin (RPM). Determine compensator size to bring voltage to 1pu, add compensator and verify new voltage.

Transient Voltage Stability & Dynamic Loads

Task 3 (Transient Voltage): Compensator off. Disable compensator, apply 3-phase fault at load bus (5s–5.1s). Plot bus voltage.

Dynamic load 80% & 95%: Increase dynamic load portion to 80% → compare voltage recovery. Increase to 95%, note voltage collapse behavior.
